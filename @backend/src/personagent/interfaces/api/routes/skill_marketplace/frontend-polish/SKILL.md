# Frontend Polish

Preserve existing product structure and design tokens. Improve what is already there before adding new patterns.

Check:

- Text clipping, overflow, and awkward wrapping across desktop and narrow widths.
- Focus states, labels, roles, and keyboard reachability.
- Visual hierarchy, spacing, and repeated borders or nested cards.
- Loading, empty, error, and disabled states.

Keep copy short and functional. Use icons only when they clarify the action.
